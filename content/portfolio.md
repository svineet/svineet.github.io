Some things I've built for learning, utility, and fun.

## AI & Agents

**[Harness Bench](https://github.com/svineet/harness-bench)** — Open-source workbench for creating, observing, analysing, and auto-improving agent harnesses. A harness = prompt + tools + skills + environment sandbox + scorecards. The coding agent (Claude Code) IS the runtime; Harness Bench extends it via MCP tools and guides it via skills. Python, FastAPI, React.

**[tgpt](https://github.com/svineet/tgpt)** — An agentic AI assistant that lives inside your terminal. Writes and executes bash commands, searches the web via Tavily, and iterates on its own mistakes. [Blog post](/post/tgpt/).

**Workflow AI** ([frontend](https://github.com/svineet/workflow-ai-fe) · [backend](https://github.com/svineet/workflow-ai-be)) — Full-stack AI workflow builder. TypeScript + Python.

## Simulations & Scientific Computing

**[physics](https://github.com/svineet/physics)** — 2D physics simulator built in Python. Rigid body dynamics, collisions, and rendering.

**[pid-simulation](https://github.com/svineet/pid-simulation)** — PID controller simulation and subsequent control using Reinforcement Learning algorithms.

**[monte-carlo-algo-analyser](https://github.com/svineet/monte-carlo-algo-analyser)** — Analysing average time complexity of algorithms via Monte Carlo sampling and statistics.

## Machine Learning

**[reinforce_cartpole](https://github.com/svineet/reinforce_cartpole)** — Vanilla Monte Carlo REINFORCE implemented in PyTorch on CartPole, leading up to Actor Critic.

**[MNIST-Digit-Recognition](https://github.com/svineet/MNIST-Digit-Recognition)** — A two-layer neural network in pure Python and NumPy for MNIST digit recognition. ~91% accuracy on Kaggle.

**[MarkovLanguageModel](https://github.com/svineet/MarkovLanguageModel)** — Trigram/bigram model that generates random sentences from the Brown corpus.
